# 使用说明

## 运行条件

- Windows。
- .NET 8 Windows Desktop Runtime，或使用自包含发布版本。
- x86 或 x64 版《恐怖黎明》进程。
- 已配置有效的 `data/MemoryConfig.json`。

## 架构选择

- x86 游戏路径：`K:\SteamLibrary\steamapps\common\Grim Dawn\Grim Dawn.exe`
- x64 游戏路径：`K:\SteamLibrary\steamapps\common\Grim Dawn\x64\Grim Dawn.exe`
- x64 游戏必须使用 x64 版本 `GrimDawnTeleporter.exe`。
- x86 游戏建议使用 x86 版本工具，也可以用 x64 版本工具检测。

## 按钮说明

- “检测进程”：查找 `Grim Dawn.exe` 并识别进程架构。
- “启动 x86”：按配置路径启动根目录下的 x86 游戏。
- “启动 x64”：按配置路径启动 `x64\Grim Dawn.exe`。
- “自动扫描坐标”：用选中传送点坐标扫描当前游戏进程，找到本次运行的动态坐标地址。
- “生成指针链”：基于当前动态坐标地址反向扫描稳定指针链，并写入 `MemoryConfig.json`。
- “读取坐标”：从游戏内存读取当前角色 X/Y/Z。
- “记录当前位置”：把当前坐标加入列表。
- “返回上一个位置”：回到最近一次传送前的位置。
- “未知扫描开始”：不知道当前坐标时，收集可能的 X/Y/Z 坐标候选。
- “静止过滤”：角色静止时过滤掉变化的候选。
- “移动过滤”：角色移动后过滤掉不变化的候选。
- “使用候选”：把剩余候选中的第一个作为当前动态坐标地址。
- “传送到选中点”：把角色坐标写入选中记录点。
- “删除选中点”：从列表中删除当前选中点。
- “保存列表”：保存到 `data/TeleportPoints.json`。
- “导入 GI 列表”：导入 `GrimInternals_TeleportList.txt`。
- “导出 GI 列表”：导出为 Grim Internals 兼容格式。
- “打开数据目录”：打开工具的数据目录。

## 快捷键

- `F6`：记录当前位置。
- `F7`：传送到选中点。

## 数据文件

工具内部使用：

```text
data\TeleportPoints.json
```

兼容 Grim Internals 的导入导出格式：

```text
GrimInternals_TeleportList.txt
```

## 自动扫描流程

自动扫描适合不想先手动找指针链的情况。它通过“选中传送点的 X/Y/Z”去扫描当前游戏内存中的相邻 `float` 坐标。

推荐流程：

1. 导入 `GrimInternals_TeleportList.txt`。
2. 让角色站到其中一个已知传送点附近。
3. 在列表中选中这个传送点。
4. 点击“自动扫描坐标”。
5. 成功后点击“读取坐标”。
6. 移动角色，再次点击“读取坐标”。
7. 如果坐标会随移动变化，就可以在本次游戏运行中使用记录和传送。

注意：自动扫描结果不保存到 `MemoryConfig.json`。工具会保存本次游戏进程的动态地址和自动扫描种子。关闭并重新打开工具时，如果游戏进程没变，会直接恢复动态地址；如果游戏也重启了，会尝试用上次初始化坐标重新扫描。

## 未知坐标扫描流程

如果没有任何已知坐标，按这个流程初始化：

1. 进入游戏，站在安全区域。
2. 点击“检测进程”。
3. 角色不要动，点击“未知扫描开始”。
4. 角色继续不要动，点击“静止过滤”。
5. 回到游戏移动一小段距离，并停下。
6. 点击“移动过滤”。
7. 如果候选数量仍然很多，重复第 4 到第 6 步。
8. 点击“使用候选”。
9. 点击“读取坐标”。
10. 移动角色后再次读取，确认坐标变化。
11. 点击“记录当前位置”保存第一个传送点。
12. 点击“生成指针链”生成稳定配置。

如果“使用候选”后读取的坐标不随角色移动变化，说明选错候选。重新执行未知扫描即可。

## 重启后的恢复条件

如果你希望初始化一次后，下次启动工具仍能自动恢复：

1. 第一次扫描时，选择一个可靠传送点。
2. 让角色站在该传送点附近。
3. 点击“自动扫描坐标”。
4. 关闭工具或关闭游戏后，下次进入游戏时仍让角色加载在该点附近。
5. 点击“检测进程”，工具会尝试自动恢复。

如果角色已经移动到其他位置，自动恢复可能失败。此时需要在列表中重新选择当前位置附近的已知传送点，再点击“自动扫描坐标”。

## 自动生成稳定指针链

如果你希望游戏重启后不再依赖自动扫描，可以生成稳定指针链。

操作流程：

1. 先完成“自动扫描坐标”。
2. 点击“读取坐标”，确认读取正常。
3. 在游戏里移动角色。
4. 再次点击“读取坐标”，确认坐标跟随变化。
5. 点击“生成指针链”。
6. 成功后关闭游戏和工具。
7. 重新启动游戏和工具。
8. 不点击“自动扫描坐标”，直接点击“读取坐标”。

如果第 8 步能读到正确坐标，说明 `MemoryConfig.json` 已经可用于跨重启读取和传送。

如果读取失败，需要重新执行自动扫描和生成指针链。必要时要在角色完全加载后再生成，避免扫描到临时坐标结构。

## 关闭进程

通过工具“启动 x86”或“启动 x64”启动的游戏，会在关闭 `GrimDawnTeleporter.exe` 时一并关闭，包括该游戏进程的子进程。

手动启动的游戏不属于工具启动的进程，不会被自动关闭。
