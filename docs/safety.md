# 安全说明

## 建议使用范围

本工具定位为本地单人便利工具，支持 x86 和 x64 版《恐怖黎明》。不要在多人联机、排行榜、竞速或公共挑战中使用。

## 存档风险

工具只读写运行时内存，不直接修改存档文件。但如果传送到墙体、地图外、未加载区域或任务脚本异常区域，仍可能造成角色卡住或游戏状态异常。

首次使用前建议备份存档目录。Steam 默认存档通常位于用户文档或 Steam userdata 目录，具体取决于是否启用云存档。

## 坐标风险

不要导入来源不明的传送列表。明显超出地图范围的坐标可能导致角色掉出地图或无法移动。

建议每次传送前保留返回点。本工具已经在传送前自动保存上一个位置，并提供“返回上一个位置”按钮。

## 版本风险

游戏更新后，内存结构和指针链可能变化。出现读取失败、坐标异常或传送无效时，不要继续尝试写入，应重新验证 `data/MemoryConfig.json`。

如果使用“自动扫描坐标”，扫描得到的是本次运行的动态地址。重启游戏、切换版本或切换进程架构后地址会失效，需要重新扫描。

x86 和 x64 的指针链不同，不能混用。x64 游戏需要单独生成 `CoordinateAddressX64`。

工具会保存上次自动扫描使用的坐标种子，并在下次检测进程时尝试自动重新扫描。这个机制不等同于稳定指针链；如果角色不在种子坐标附近，恢复会失败。

自动生成的指针链必须通过重启游戏验证。不要只因为生成成功就直接在重要角色或危险区域使用传送。

未知坐标扫描会从大量内存候选中筛选坐标地址。第一次使用候选后，只读取和小距离验证，不要立刻传送到远距离坐标。

## 关闭工具时的进程处理

如果游戏是通过工具启动的，关闭工具时会一并关闭该游戏进程及其子进程。关闭前请确认游戏状态已经安全保存。

## 权限和安全软件

读写游戏进程内存可能触发安全软件警告。工具不隐藏进程、不注入 DLL、不联网。如无法打开游戏进程，可以尝试以管理员权限运行工具。
