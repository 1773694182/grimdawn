# Grim Dawn 坐标传送工具

这是一个外部窗口工具，用于《恐怖黎明》x86/x64 进程的坐标记录与传送。目标是本地单人使用，不注入 DLL，不做游戏内叠加层，不支持多人联机。

## 已实现功能

- x64 Launcher 可注入 `GrimDawnTeleporter.Plugin.dll` 到 x64 Grim Dawn。
- Launcher 与 Plugin 已通过 Named Pipe 建立基础通信。
- 检测 `Grim Dawn.exe` 进程并识别 x86/x64 架构。
- 一键启动 x86 游戏：`K:\SteamLibrary\steamapps\common\Grim Dawn\Grim Dawn.exe`。
- 一键启动 x64 游戏：`K:\SteamLibrary\steamapps\common\Grim Dawn\x64\Grim Dawn.exe`。
- 读取当前角色坐标。
- 可用选中传送点自动扫描本次运行的动态坐标地址。
- 自动扫描成功后会保存初始化种子；下次工具启动并检测游戏时，会尝试自动恢复坐标地址。
- 可基于自动扫描得到的动态地址生成稳定指针链，并写入 `MemoryConfig.json`。
- 不知道任何坐标时，可用“未知扫描开始/静止过滤/移动过滤/使用候选”定位当前位置。
- 记录当前位置到 `data/TeleportPoints.json`。
- 显示、搜索、编辑、删除传送点。
- 传送到选中坐标。
- 传送前自动保存上一个位置，并支持返回。
- 导入和导出 `GrimInternals_TeleportList.txt` 格式。
- WPF 自适应窗口，支持 1080p、2K、4K 和系统 DPI 缩放。
- 全局快捷键：`F6` 记录当前位置，`F7` 传送到选中点。
- 关闭工具时，会关闭由本工具启动的游戏进程及其子进程。

## 自动扫描坐标地址

工具提供“自动扫描坐标”按钮，用于在当前游戏进程中查找本次运行的动态坐标地址。

使用条件：

- 列表里已有一个可靠传送点，例如从 `GrimInternals_TeleportList.txt` 导入的坐标。
- 角色当前正站在这个传送点附近。
- 游戏必须是受支持的 x86 或 x64 `Grim Dawn.exe`。

使用流程：

1. 进入单人游戏，并让角色站在已知传送点附近。
2. 在工具列表中选中对应传送点。
3. 点击“自动扫描坐标”。
4. 扫描成功后，工具会启用本次会话动态地址。
5. 点击“读取坐标”验证数值是否正确。
6. 移动角色后再次读取，确认坐标变化。
7. 点击“生成指针链”，把稳定指针链写入 `MemoryConfig.json`。
8. 重启游戏后点击“读取坐标”，验证稳定配置是否生效。

恢复规则：

- 如果只是关闭并重新打开 `GrimDawnTeleporter.exe`，但游戏没有重启，工具会优先恢复同一个游戏进程的动态地址。
- 如果游戏也重启了，工具会用上次初始化时保存的已知坐标作为种子重新扫描。
- 游戏重启后的自动恢复要求角色加载后仍站在上次初始化坐标附近。

限制：

- 自动扫描得到的是动态地址，只保证当前这次游戏运行可用。
- 重启游戏后，工具会尝试用上次初始化坐标重新扫描；如果角色不在该坐标附近，需要手动重新扫描。
- 仅点击“自动扫描坐标”不会生成稳定指针链；需要再点击“生成指针链”。
- 如果扫描不到，请确认角色是否真的站在选中坐标附近。

## 不知道坐标时怎么初始化

如果你没有任何已知传送点，也不知道角色当前坐标，可以使用未知坐标扫描。

操作流程：

1. 进入单人游戏，让角色站在安全开阔区域。
2. 回到工具，点击“检测进程”。
3. 角色保持静止，点击“未知扫描开始”。
4. 继续保持静止，点击“静止过滤”。
5. 回到游戏，移动一小段距离后停下。
6. 回到工具，点击“移动过滤”。
7. 如果候选数量仍然很多，重复“静止过滤 -> 移动一小段 -> 移动过滤”。
8. 候选较少后，点击“使用候选”。
9. 点击“读取坐标”，移动角色后再次读取，确认坐标会变化。
10. 点击“记录当前位置”，保存你的第一个传送点。
11. 点击“生成指针链”，生成跨重启配置。

未知扫描不需要提前知道坐标。它通过“静止时坐标不变、移动后坐标变化”过滤内存候选。

## 自动生成指针链

“生成指针链”会在自动扫描成功后执行反向指针扫描，寻找从静态模块地址到玩家坐标的指针路径。x86 和 x64 会使用不同的指针宽度与配置项。

当前优先搜索这些模块：

```text
Grim Dawn.exe
Game.dll
Engine.dll
```

生成成功后，工具会自动更新：

```text
data\MemoryConfig.json
```

推荐验证流程：

1. 进入游戏，站在已知坐标点附近。
2. 选中对应传送点。
3. 点击“自动扫描坐标”。
4. 点击“读取坐标”，确认数值正确。
5. 移动角色，再次读取，确认坐标变化。
6. 点击“生成指针链”。
7. 关闭游戏和工具。
8. 重新启动游戏和工具。
9. 不执行“自动扫描坐标”，直接点击“读取坐标”。
10. 如果能读到正确坐标，说明指针链对当前版本可用。

限制：

- 指针链生成是启发式扫描，不能保证每个版本都能一次成功。
- 生成成功后仍必须通过重启游戏验证。
- 游戏更新后指针链可能失效，需要重新生成。
- 如果扫描耗时较长，窗口可能短暂无响应。

## 进程关闭规则

如果通过工具里的“启动 x86”或“启动 x64”启动了游戏，那么关闭 `GrimDawnTeleporter.exe` 时，工具会使用进程树关闭方式结束该游戏进程及其子进程。

如果游戏是你手动从 Steam 或文件管理器启动的，工具不会在关闭时结束它。

## 构建

```powershell
./build-release.ps1
```

如需构建 Debug 版本：

```powershell
./build-release.ps1 -Configuration Debug
```

脚本会依次重新生成 x64 插件 DLL、x86 工具 EXE、x64 工具 EXE，并把 `GrimDawnTeleporter.Plugin.dll` 复制到 x64 工具输出目录。

构建产物位于：

```text
src\GrimDawnTeleporter\bin\x86\Release\net8.0-windows\win-x86\
src\GrimDawnTeleporter\bin\x64\Release\net8.0-windows\win-x64\
```

x64 游戏必须使用 x64 版本工具。x86 游戏可以继续使用 x86 版本工具。

## 首次配置

工具支持两种坐标地址来源。第一种是“自动扫描坐标”得到的本次会话动态地址。第二种是当前游戏版本和架构对应的稳定坐标指针链。稳定指针链默认配置文件位于：

```text
data\MemoryConfig.json
```

默认内容中的 `BaseOffset` 和 `XOffsets/YOffsets/ZOffsets` 为空，占位配置不能读取或写入坐标。你需要先用本机游戏版本验证坐标地址，然后填入类似结构：

```json
{
  "ProcessName": "Grim Dawn",
  "GameExePathX86": "K:\\SteamLibrary\\steamapps\\common\\Grim Dawn\\Grim Dawn.exe",
  "GameExePathX64": "K:\\SteamLibrary\\steamapps\\common\\Grim Dawn\\x64\\Grim Dawn.exe",
  "PreferredArchitecture": "Auto",
  "CoordinateAddressX86": {
    "ModuleName": "Grim Dawn.exe",
    "BaseOffset": "0x123456",
    "XOffsets": ["0x10", "0x20", "0x30"],
    "YOffsets": ["0x10", "0x20", "0x34"],
    "ZOffsets": ["0x10", "0x20", "0x38"]
  },
  "CoordinateAddressX64": {
    "ModuleName": "Grim Dawn.exe",
    "BaseOffset": "0x123456",
    "XOffsets": ["0x10", "0x20", "0x30"],
    "YOffsets": ["0x10", "0x20", "0x34"],
    "ZOffsets": ["0x10", "0x20", "0x38"]
  }
}
```

偏移支持十六进制字符串，例如 `0x1234`，也支持十进制字符串。

## 使用流程

1. 启动工具。
2. 点击“启动 x86”或“启动 x64”，也可以手动启动对应架构的 `Grim Dawn.exe`。
3. 进入单人游戏并加载角色。
4. 点击“检测进程”，确认工具识别到正确架构的游戏进程。
5. 点击“读取坐标”。
6. 点击“记录当前位置”或按 `F6` 保存坐标。
7. 在列表中选择传送点。
8. 点击“传送到选中点”或按 `F7` 执行传送。

## Grim Internals 格式

支持导入和导出以下格式：

```text
名称, X, Y, Z,
```

示例：

```text
heigumeng-taernuoshi, -5993.29, 29.3432, 628.284,
```

## 安全边界

- 仅建议本地单人模式使用。
- 不建议多人联机使用。
- 不会修改 `.gdc` 存档文件。
- 传送到非法坐标可能导致卡住、掉出地图或触发异常状态。
- 第一次使用前建议备份存档。
- 游戏更新后坐标指针链可能失效，需要重新验证 `MemoryConfig.json`。
- 读写其他进程内存可能被安全软件提示风险，这是此类工具的正常特征。
